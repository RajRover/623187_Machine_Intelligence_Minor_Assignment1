## Reproducing Every Figure and Table

All figures are saved programmatically to `figures/`.  
All random seeds are fixed (`SEED = 42` throughout) so every run is **exactly reproducible**.

### Run everything at once

```bash
# Linux / macOS
python src/run_all.py

# Windows (required to avoid Unicode encoding errors in PowerShell)
python -X utf8 src/run_all.py
```

This executes Problems 1, 2, 3, and 4 in sequence and prints all tables to stdout.
Total runtime is approximately **10-15 seconds**.

> **Windows users:** Always pass `-X utf8` when running any module from this
> project in PowerShell / cmd, otherwise Python's default `cp1252` encoding
> will raise `UnicodeEncodeError` on special characters in print output.

### Run individual problems

```bash
python -X utf8 src/run_all.py --q1   # Problem 1 - vectorization benchmark
python -X utf8 src/run_all.py --q2   # Problem 2 - polynomial fitting
python -X utf8 src/run_all.py --q3   # Problem 3 - bias-variance decomposition
python -X utf8 src/run_all.py --q4   # Problem 4 - EDA
```

## Notes on Reproducibility

- Problem 3 uses `S=200` by default; the verification table is re-run with `S=2000` immediately after (both printed to stdout) to demonstrate that the discrepancy shrinks as MC noise decreases.
- Problem 1's loop implementation is timed only on `N=200` points; the N=2000 runtime is **extrapolated** via O(N^2) scaling (factor of 100x) since running the pure-Python nested loop on 4,000,000 pairs would take several minutes.
- The `figures/` directory is intentionally committed to the repository so that a grader can view all plots without running the code. Re-running the code will overwrite them with identical files.
